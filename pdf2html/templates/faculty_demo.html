    About this demo & accessibility review

    This is a local faculty-upload concept, not a live university service. It uses our existing local PDF extractor and static HTML checks. It does not use AI, perform OCR, certify WCAG compliance, or create a tagged PDF. Scans, equations, reading order, complex tables, and image descriptions may need substantial work.

    Outputs stay in the local demo folder until manually removed. This session's links require this browser's demo cookie and stop working after the demo server restarts. There is no campus sign-in, email delivery, or public sharing. Do not expose this demonstration server to the internet.
